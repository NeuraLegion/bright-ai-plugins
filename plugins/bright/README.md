# bright — Umbrella

One-command install of the default Bright skill set:

- **bright-scan** — discover, scan, fix, rescan
- **bright-api** — posture & findings reporting
- **bright-auth** — configure & test authentication
- **bright-ci** — wire Bright into CI/CD

```
/plugin install bright@brightsec
```

For a target-app scaffolder, install **bright-lab** separately.
