# bright-api — Report & Analyze

Queries the Bright platform to give you a picture of your security posture across all your
projects. Your agent authenticates, pulls vulnerability and scan data, and presents actionable
summaries.

```
Question → Authenticate → Query platform → Present results → Suggest next actions
```

**Use it when:** you want to know what needs attention, what changed since the last scan, or which
projects are falling behind.

See [`skills/bright-api/SKILL.md`](./skills/bright-api/SKILL.md).
